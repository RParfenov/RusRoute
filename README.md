# RusRoute — сервис планирования туристических маршрутов

RusRoute — это веб-приложение для планирования путешествий по городам России. Сервис позволяет выбирать пункты отправления и назначения, учитывать прогноз погоды и сравнивать различные варианты поездок.

---

## 📁 Структура проекта
```
RusRoute/
├── analysis/
├── data/
├── db/
├── source/
├── static/
├── templates/
├── .gitignore
├── LICENSE
├── README.md
└── requirements.txt
```
### Описание папок:

- **analysis/** - анализ данных 
- **data/** — содержит файлы с данными о городах, маршрутах, погоде и популярных направлениях.
- **db/** — хранилище базы данных SQLite (`rusroute.db`), а также картинок графиков.
- **source/** — исходный код на Python (основное приложение, обработчики, графики, работа с БД).
- **static/** — CSS-стили, JavaScript, иконки, логотипы.
- **templates/** — HTML-страницы приложения.

---

## 🚀 Функциональность

### Основные возможности:
- Выбор городов отправления и назначения
- Учет прогноза погоды при планировании
- Сравнение маршрутов по времени, цене и виду транспорта
- Визуализация данных в виде графиков (столбчатых и линейных)
- История запросов пользователя
- Фильтрация маршрутов по предпочтениям

---

### Страницы сайта:
1. **Главная страница** — вход в систему и начало работы
2. **Страница выбора маршрута** — выбор города откуда и куда, а также даты. Показ городов через static api.
3. **Страница с картой** — возможность оценить город
4. **Страница с информацией о маршруте** — детали поездки, графики, текстовые данные

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <ссылка-на-репозиторий>
cd RusRoute
```
### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
```env
DATABASE_RELATIVE_PATH=db/rusroute.db
SECRET_KEY=ваш_секретный_ключ
YANDEX_STATIC_API_KEY=ваш_ключ_яндекс_карт
```
- `SECRET_KEY` — используется для сессий и безопасности (можно сгенерировать случайную строку).
- `YANDEX_STATIC_API_KEY` — ключ для работы со static апи Яндекса.

### 4. Запуск приложения

```bash
cd source
python app.py
```
